# gate io ปลอดภัยไหม: ตรวจใบอนุญาต หลักฐานเงินสำรอง 117% และเช็กลิสต์ก่อนโอนเงินจริงจากไทย

## คำตอบสั้น ๆ ก่อน

Gate ไม่ใช่เว็บผีที่เพิ่งเปิดเมื่อวาน ก่อตั้งปี 2013 เคยมีชื่อว่า Bter แล้วเปลี่ยนเป็น Gate.io ปลายปี 2017 และเปลี่ยนอีกครั้งเป็น Gate เมื่อกลางปี 2025 ตอนนี้มีผู้ใช้ราว 59 ล้านบัญชี และมีใบอนุญาตหรือการจดทะเบียนในหลายประเทศจริง

แต่คำถามว่า "ปลอดภัยไหม" ไม่ควรจบที่ประโยคนั้น เพราะGate ยังมีอีกด้านที่รีวิวส่วนใหญ่เลื่อนผ่าน นั่นคือไม่มีใบอนุญาตในเขตอำนาจที่ตัวเองจดทะเบียน ไม่มีกองทุนชดเชยจากรัฐ และมีเหตุการณ์ด้านความปลอดภัยเป็นของตัวเองหลายครั้ง

> ถ้าคุณจะฝากเงินก้อนโตไว้บนกระดานเทรดใดก็ตาม คำถามที่ถูกต้องไม่ใช่ "มันโกงไหม" แต่คือ "ถ้ามันมีปัญหา ใครรับผิดชอบ และฉันมีทางถอนออกทันไหม"

## Gate คือใคร และทำไมคนถึงสงสัยเรื่องความปลอดภัย

Gate เกิดในจีนปี 2013 ในชื่อ Bter.com ก่อตั้งโดยดร. ฮั่น (Lin Han) ซึ่งยังเป็นซีอีโอจนถึงปัจจุบัน ก่อนย้ายฐานออกนอกจีนหลังทางการจีนปิดประตูคริปโต แล้วเปลี่ยนชื่อเป็น Gate.io ปลายปี 2017 ปัจจุบันสำนักงานใหญ่ทางกฎหมายอยู่ที่หมู่เกาะเคย์แมน

ตัวเลขที่แพลตฟอร์มประกาศในรายงานความโปร่งใสเดือนกรกฎาคม 2026:

- ผู้ใช้รวมเกิน 59 ล้านบัญชี เพิ่มขึ้น 2.3 ล้านบัญชีในเดือนนั้นเดือนเดียว
- รองรับสินทรัพย์ดิจิทัลราว 4,800 รายการ บวกหุ้นและ ETF อีกกว่า 12,500 รายการ
- ปริมาณเทรดอนุพันธ์ในเดือนนั้นอยู่ที่ราว 7.4 แสนล้านดอลลาร์

จุดที่ทำให้คนลังเลคือประวัติศาสตร์ของมัน ไม่ใช่ขนาด ในปี 2015 ตอนยังชื่อ Bter กระดานเทรดถูกเจาะกระเป๋าเย็นหายไปราว 7,170 BTC (ประมาณ 1.75 ล้านดอลลาร์ในตอนนั้น) ต่อมามีข้อกล่าวหาว่าปี 2018 ถูกแฮกเกอร์ที่เชื่อมโยงกับเกาหลีเหนือขโมยไปราว 230 ล้านดอลลาร์ และไม่แจ้งลูกค้า ซึ่งเป็นการเปิดเผยของ ZachXBT ในปี 2022 ทีมงานของ Gate ไม่ได้ปฏิเสธอย่างเป็นทางการ

นอกจากนั้นยังมีกรณี StatCounter supply-chain attack ปี 2018 ที่ ESET พบว่ามีการฝังสคริปต์สลับที่อยู่ BTC ในหน้าเว็บถอนเงินของ Gate และปี 2019 ที่ Ethereum Classic ถูกโจมตี 51% ทำให้ Gate เสีย ETC ไปราว 54,200 เหรียญ

ทั้งหมดนี้เป็นเรื่องที่ผ่านมาแล้วหลายปี และโครงสร้างความปลอดภัยเปลี่ยนไปมาก แต่การรู้ว่ามันเคยเกิดอะไรขึ้น สำคัญกว่าการอ่านประโยค "ระบบปลอดภัยระดับธนาคาร"

ประเด็นที่ต้องพูดตรง ๆ คือ Gate ไม่ได้อยู่ในระบบที่มีกองทุนชดเชยผู้ฝากแบบที่สถาบันการเงินหลายแห่งมี ถ้า Gate ล้มเป็นล้มเป็นทางการ ทรัพย์สินของลูกค้าจะเข้าไปอยู่ในกระบวนการ liquidation ไม่ใช่มีหน่วยงานรัฐจ่ายคืนให้

และมีอีกสองเอกสารที่คนมักไม่รู้:

- **เมษายน 2025** หน่วยงานกำกับดูแลหมู่เกาะเคย์แมน (CIMA) ออกประกาศสาธารณะว่า Gate.io และ Gate Global Corp ไม่เคยได้รับใบอนุญาตให้ดำเนินธุรกิจในหรือจากหมู่เกาะเคย์แมน นี่คือแจ้งเตือนจากเขตที่ Gate ตั้งสำนักงานใหญ่ทางกฎหมายอยู่เอง
- **พฤษภาคม 2026** คณะกรรมการตลาดการเงินชิลี (CMF) ขึ้นบัญชี Gate.io และนิติบุคคลในเครือหลายแห่งว่าไม่ได้ลงทะเบียนหรือได้รับอนุญาตให้ให้บริการภายใต้การกำกับของ CMF

การที่กระดานเทรดคริปโตระดับโลกถูกขึ้นบัญชีแบบนี้ไม่ใช่เรื่องแปลก เพราะหลายตัวเลือกใช้โครงสร้างนิติบุคคลแยกตามภูมิภาคอยู่แล้ว แต่คุณควรเข้าใจว่า "มีใบอนุญาต" กับ "ได้รับการคุ้มครองในประเทศที่คุณอยู่" เป็นคนละเรื่อง

## หลักฐานเงินสำรอง 117% เช็คได้แค่ไหน

Gate เป็นหนึ่งในกระดานเทรดที่เผยแพร่รายงาน Proof of Reserves (PoR) เป็นรายเดือน ฉบับล่าสุดที่ผมอ้างถึงคือวันที่ 27 กรกฎาคม 2026 ตัวเลขหลัก:

- อัตราสำรองรวม **117%** แปลว่าทุก ๆ 1 ดอลลาร์ที่เป็นหนี้ต่อผู้ใช้ มีสินทรัพย์ค้ำอยู่ประมาณ 1.17 ดอลลาร์
- BTC: ผู้ใช้ถือ 21,557 BTC ขณะที่แพลตฟอร์มถือ 26,775 BTC → สำรอง 124.2%
- ETH: ผู้ใช้ถือ 374,348 ETH แพลตฟอร์มถือ 456,798 ETH → 122.02%
- GT: 131.13% และ XRP: 116.5%
- Stablecoin (USDT, USDC, USD1, GUSD): หนี้ราว 1.336 พันล้าน กับสำรองราว 1.59 พันล้าน → 118.97%
- ครอบคลุมสินทรัพย์ผู้ใช้เกือบ 500 ประเภท

ฝั่งเทคนิค Gate ใช้ Merkle tree ให้ผู้ใช้ตรวจเองได้ว่ายอดของตัวเองถูกรวมอยู่ใน snapshot และใช้ zk-SNARKs เพื่อพิสูจน์ยอดรวมโดยไม่เปิดเผยยอดของแต่ละคน วิธีการนี้ผ่านการตรวจสอบโดยบริษัทความปลอดภัย Hacken ในเดือนมกราคม 2024

ข้อจำกัดที่ต้องรู้: PoR เป็นภาพ ณ เวลาใดเวลาหนึ่ง ไม่ใช่การตรวจสอบฐานะการเงินต่อเนื่อง และไม่ใช่การรับประกันว่าถ้าถอนพร้อมกันทั้งระบบจะจ่ายไหว อัตราสำรองของ Gate แกว่งอยู่ระหว่าง 115% ถึง 128% ในรอบสองปีที่ผ่านมา ซึ่งเกิน 100% มาตลอด แต่ตัวเลขนี้ไม่ใช่เกราะกันกระสุน

## เหตุการณ์ที่เพิ่งเกิด และเป็นเหตุผลที่คนถามคำถามนี้มากขึ้น

ช่วงที่ผ่านมามีกรณีที่ถูกพูดถึงหนักในชุมชนคริปโต ผู้ใช้รายหนึ่งที่ผ่านการยืนยันตัวตนแล้วอ้างว่าทรัพย์สินมูลค่าราว 1.7 ล้านดอลลาร์ถูกถอนออกจากบัญชีโดยไม่ได้รับอนุญาต ทั้งที่เปิดทั้งการยืนยันทางโทรศัพท์ Google Authenticator และอีเมล และอ้างว่าไม่ได้รับรหัส SMS ใด ๆ

Gate ตอบครั้งแรกว่าเป็นกรณีเฉพาะ ไม่พบช่องโหว่ของระบบ จากนั้นออกมาขอโทษเมื่อวันที่ 11 ว่า "ท่าทีในช่วงแรกไม่เหมาะสม และไม่ได้ให้น้ำหนักกับความรู้สึกของผู้ใช้" บริษัทระบุว่าเส้นทางที่ผู้ไม่หวังดีใช้มีความสมบูรณ์ของข้อมูลสูงผิดปกติ มีอีเมลและ SMS แจ้งเตือนไปหาลูกค้าเมื่อมีการขอเปลี่ยนการตั้งค่าความปลอดภัย และที่อยู่ IP อยู่ในพื้นที่เดียวกับที่ผู้ใช้เคยเข้าใช้งาน

สำนักความปลอดภัยบล็อกเชน Bitrace ตรวจเส้นทางเงินและพบว่ามีการถอน 49.96 ETH, 746,475 HSK และ 1.565 ล้าน USDT ออกไป โดยเส้นทางเงินเชื่อมโยงกับ Newpay

หลังจากนั้นมีรายงานอ้างข้อมูลจาก DeFiLlama ว่า Gate มีเงินไหลออกสุทธิราว 207 ล้านดอลลาร์ภายในเจ็ดวัน ตัวเลขนี้ไม่ได้แปลว่า Gate ล้มละลายหรือถอนเงินไม่ได้ เพราะแพลตฟอร์มยังดำเนินงานปกติ แต่แปลว่าความเชื่อมั่นสั่นได้เร็วมากเมื่อผู้ใช้รู้สึกว่ากระบวนการรับเรื่องไม่โปร่งใส

บทเรียนสำหรับคนไทยไม่ใช่ "อย่าใช้ Gate" แต่คือถ้าคุณมีเงินในบัญชีมากกว่าที่คุณยอมเสียได้ คุณต้องคิดเรื่องการถอนไปเก็บเอง การแยกบัญชี และการตั้งข้อจำกัดของบัญชี มากกว่าหวังพึ่งทีมซัพพอร์ต

## ความเสี่ยงที่ตัวแอปไม่ได้เป็นคนสร้าง

สัดส่วนความเสียหายจริงของผู้ใช้คริปโตส่วนใหญ่ไม่ได้มาจากแพลตฟอร์มถูกแฮก แต่มาจากการที่ผู้ใช้ถูกหลอกให้ส่งข้อมูลเอง และนี่คือจุดที่ Gate ออกประกาศเตือนของตัวเอง

รูปแบบที่พบบ่อยคือมิจฉาชีพได้เบอร์โทรหรืออีเมลจากช่องทางสีเทา แล้วโทรอ้างว่าเป็นเจ้าหน้าที่ Gate โดยหมายเลขที่โชว์มักเป็นหมายเลขจากเกาหลี สหรัฐฯ หรือฮ่องกง เนื้อหาที่ใช้พูดมีตั้งแต่ "ระบบตรวจพบบัญชีคุณเกี่ยวข้องกับเหรียญผิดกฎหมาย" "ต้องอัปเกรดความปลอดภัย ไม่งั้นทรัพย์สินจะหาย ให้ย้ายไปกระเป๋าเงินก่อน" ไปจนถึง "ต้องดาวน์โหลดโปรแกรมประชุมทางวิดีโอเพื่อยืนยันตัวตน"

Gate ระบุชัดว่าทางการและเจ้าหน้าที่จะไม่ขอรหัสผ่าน รหัส SMS หรืออีเมล ไม่ให้ดาวน์โหลดแอปใด ๆ และไม่ให้โอนเงินหรือถอนทรัพย์สินไปที่ใดทั้งสิ้น นอกจากนี้ยังไม่มีการเก็บค่าลงเหรียญหรือเงินมัดจำใด ๆ ผ่านการติดต่อโดยตรง

สิ่งที่ทำได้จริงเพื่อลดความเสี่ยงของคุณเอง:

1. **เปิดรหัสป้องกันฟิชชิง (Anti-phishing code)** เพื่อแยกอีเมลจริงของแพลตฟอร์มออกจากอีเมลปลอม
2. **ตั้ง Whitelist ที่อยู่กระเป๋าถอนเงิน** ให้ถอนออกได้เฉพาะที่อยู่ที่คุณลงทะเบียนไว้ และเพิ่มที่อยู่ใหม่ต้องรอบัญชี
3. **ใช้แอป Authenticator แยกจาก SIM** เพราะกรณีที่อ้างถึงข้างต้นเกิดขึ้นแม้มี SMS OTP
4. **รู้ว่าการเปลี่ยนการตั้งค่าความปลอดภัยจะถูกล็อกการถอนไว้ 24 ชั่วโมง** ซึ่งเป็นกลไกของแพลตฟอร์ม ไม่ใช่ระบบพัง
5. **ตรวจที่อยู่เว็บก่อนพิมพ์รหัสผ่านทุกครั้ง** เว็บไซต์ปลอมที่ชื่อคล้ายกันเป็นสาเหตุอันดับหนึ่ง
